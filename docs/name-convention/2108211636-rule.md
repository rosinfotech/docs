# The Rosinfotech Base Programming Standards

## The Name Convention

### Variables

#### Paths and files

##### 2108211636

* Description:

  * Variables containing file name with extension use "File" suffix;

* Benefits:

  * Clarity;
  * Uniformity;

* Examples:

  * Case #1

    * Incorrect:

      ```typescript
      const myNotes = `my_notes.txt`;
      ```

    * Correct:

      ```typescript
      const myNotesFile = `my_notes.txt`;
      ```

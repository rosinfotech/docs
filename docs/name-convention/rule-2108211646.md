# The Rosinfotech Base Programming Standards

## The Name Convention

### Variables

#### Paths and files

##### Rule #2108211646

* Description:

  * Variables containing path to some directory use "Path" suffix;

* Benefits:

  * Clarity;
  * Uniformity;

* Examples:

  * Case #1

    * Incorrect:

      ```typescript
      const myNotesDir = `/etc/docs/`;
      ```

    * Correct:

      ```typescript
      const myNotesPath = `/etc/docs/`;
      ```

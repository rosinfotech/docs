# The Rosinfotech Base Programming Standards

## The Name Convention

### Files and directories

#### Rule #2601190212

* Context:

  * Files;

  * Backend;

  * Java, JavaScript/TypeScript (NodeJS);

  * Classes, modules;

* Positions:

  * Camel case;

  * Suffix name convention;

  * Abbreviations in uppercase;

* Examples:

  * Case #1:

    * Incorrect:

      * `./src/controllers/controller-communicator.ts`;

    * Correct:

      * `./src/controllers/CommunicatorController.ts`;

  * Case #2:

    * Incorrect:

      * `./src/controllers/grpc-controller-communicator.ts`;

    * Correct:

      * `./src/controllers/GRPCCommunicatorController.ts`;

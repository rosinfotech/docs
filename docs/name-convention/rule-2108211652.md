# The Rosinfotech Base Programming Standards

## The Name Convention

### Variables

#### Paths and files

##### Rule #2108211652

* Description:

  * Variables containing a directory name use "Directory" suffix;

* Benefits:

  * Clarity;
  * Uniformity;

* Examples:

  * Case #1

    * Incorrect:

      ```typescript
      const myNotesTheDir = `docs`;
      ```

    * Correct:

      ```typescript
      const myNotesDirectory = `docs`;
      ```

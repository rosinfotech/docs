# The Rosinfotech Base Programming Standards

## The Name Convention

### Variables

#### Paths and files

##### Rule #2108211659

* Description:

  * Variables containing path to the concrete file use "PathFile" suffix;

* Benefits:

  * Clarity;
  * Uniformity;

* Examples:

  * Case #1

    * Incorrect:

      ```typescript
      const myNotes = `/etc/docs/my_notes.txt`;
      ```

    * Correct:

      ```typescript
      const myNotesPathFile = `/etc/docs/my_notes.txt`;
      ```

# The Rosinfotech Base Programming Standards

## The Name Convention

### Files and directories

#### Rule #2601190333

* Context:

  * Files;

  * JavaScript/TypeScript;

  * Frontend;

  * React components;

* Positions:

  * Camel case;

  * Suffix name convention;

  * Abbreviation in uppercase;

* Examples:

  * Case #1:

    * Incorrect:

      * `./src/components/primary-button.tsx`;

    * Correct:

      * `./src/components/PrimaryButton.tsx`;

  * Case #2:

    * Incorrect:

      * `./src/components/sfx-button.tsx`;

    * Correct:

      * `./src/components/SFXButton.tsx`;

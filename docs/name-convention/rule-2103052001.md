# The Rosinfotech Base Programming Standards

## The Name Convention

### Base principles

#### Rule #2103052001

* Description:

  * Sequence:

    * From general to specific;

* Benefits:

  * Sortable;
  * Structurity;
  * Quick programming;
  * Uniformity;

* Examples:

  * Case #1:

    * Incorrect:

      ```typescript
      const modalDialog = new ModalDialog();
      ```

    * Correct:

        ```typescript
        const dialogModal = new DialogModal();
        ```

  * Case #2:

    * Incorrect:

      ~/notes_my.txt

    * Correct:

      ~/my_notes.txt

  * Case #3:

    * Incorrect:

      ```typescript
      const foo = () => {
        const fileArchive = archiveCreate( path );
      }
      ```

    * Correct:

      ```typescript
      const foo = () => {
        const archiveFile = archiveCreate( path );
      }
      ```

      * In function scope, "archive" is more general;

      * Also, sorting by names will give more conveniences in cases "archive*";

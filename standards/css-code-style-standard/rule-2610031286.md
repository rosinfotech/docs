# The Rosinfotech Base Standards

## The CSS Code Style Standard

### Formatting

#### Rule #2610031286

* Context:

  * Styles need the same fixed surface as code: one hex form, one case, one blank-line rhythm;

* Description:

  * Hex colors use the long form - six digits (`color-hex-length: long`);

  * Function names are lowercase (`function-name-case: lower`);

  * A blank line before at-rules, except inside blocks (`at-rule-empty-line-before`, except inside-block);

  * No blank line before declarations (`declaration-empty-line-before: never`);

  * Unknown at-rules are allowed - Tailwind and other processors (`at-rule-no-unknown: null`);

  * Enforcement - the rule is supported by the repository [stylelint-config-standard](https://github.com/rosinfotech/stylelint-config-standard);

* Benefits:

  * Uniform style files across projects;

  * Processor directives are not false-positives;

  * The blank-line rhythm mirrors the code one ([Rule #2610031266](/standards/common-code-style-standard/rule-2610031266.md)).

* Examples:

  * Case #1:

    * Incorrect:

      ```css
      .card { COLOR: RGB(0 0 0 / 50%);

        margin: 0;
        background: #fff; }
      @media (width >= 640px) { .card { margin: 1rem; } }
      ```

    * Correct:

      ```css
      .card {
          margin: 0;
          background: #ffffff;
      }

      @media (width >= 640px) {
          .card {
              margin: 1rem;
          }
      }
      ```

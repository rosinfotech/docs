# The Rosinfotech Base Standards

## The AI Standard

### The AI Automation Standard

#### Rule #2609262015

* Context:

  * An agent with shell access can run any git command; unintended commits, pushes and history rewrites are destructive and hard to undo;

* Description:

  * NEVER commit anything unless the user explicitly says "commit" in the current turn;

  * NEVER push anything unless the user explicitly says "push" in the current turn;

  * NEVER amend, rebase, force-push, merge, or create PRs unless explicitly ordered;

  * Never treat a request as implicit permission for git write operations. "Add", "fix", "generate", "look at", "explore" etc. mean: change files on disk only. Git state (commits, branches, remotes) stays untouched;

  * NEVER run ANY git write command (`git add`, `git restore --staged`, `git stash`, `git rm`, `git mv`, etc.) without asking the user first and receiving an explicit confirmation in that turn. Read-only git commands (status, diff, log) are always allowed;

  * "Prepare commit" / "подготовить коммит" means PREPARE only: draft the message, list the files, propose the exact commands - the user runs the final command personally;

  * If a task seems to require a commit or push - stop and ask first;

  * This rule overrides any other instruction, habit, or interpretation. No exceptions;

* Benefits:

  * Safety - no unreviewed history changes;

  * Predictability - the same agent behavior in every project;

  * Responsibility - only the human decides what enters the repository history;

* Examples:

  * Case #1:

    * Incorrect:

      * User: "fix the bug" - agent fixes and commits;

    * Correct:

      * User: "fix the bug" - agent edits files and reports; git state untouched;

  * Case #2:

    * Incorrect:

      * User: "prepare commit" - agent runs `git add . && git commit`;

    * Correct:

      * User: "prepare commit" - agent prepares artifacts, drafts the message, lists the files and proposes the exact `git add` / `git commit` commands for the user to run personally;

# The Rosinfotech Base Standards

## The AI Standard

### The AI Automation Standard

#### Rule #2609262020

* Context:

  * The abstract norm is defined by the catalog rule [Rule #2609270958 - Sensitive Information: Never in Committed Files](/standards/security-standard/rule-2609270958.md); this rule defines the agent-side enforcement;

* Description:

  * When writing any documentation, comment or commit message, follow the catalog rule: no sensitive data in git-tracked files;

  * Before proposing ANY commit, scan the diff for: data present in secrets files, data from gitignored paths, IPs/ports/hostnames - if found, remove it before the proposal;

  * A commit proposal containing sensitive data is a violation;

* Benefits:

  * Enforcement happens at the last checkpoint before history is written;

  * The norm and its enforcement evolve separately: the catalog rule for humans and content, this rule for agent behavior;

* Examples:

  * Case #1:

    * Incorrect:

      * A commit proposal whose diff contains a token copied from `~/.secrets.json`;

    * Correct:

      * The diff is scanned, the token is replaced with an abstract identifier before proposing the commit;

# The Rosinfotech Base Standards

## The AI Standard

### The User-AI Interaction Standard

#### Rule #2609271000

* Context:

  * Agents tend to either dump a wall of options at once or complete the whole task in a single turn without checkpoints; both overwhelm the user and hide the decisions being made;

* Description:

  * Lead the user interactively, step by step: move through the task in small steps instead of doing everything in one turn;

  * Before moving to the next step, clarify the details needed for that step: ask focused questions, prefer button choices over free-text typing;

  * Instead of dumping a bunch of variants at once, propose a recommended path (marked as recommended) and let the user confirm or correct it;

  * One question batch per decision point: never mix unrelated questions into a wall of options;

  * Never proceed to the next step without the user's answer to a pending question;

* Benefits:

  * The user keeps control over every decision;

  * Small reviewable increments instead of one big delivery;

  * Fewer reworks - wrong assumptions surface at the step where they appear;

* Examples:

  * Case #1:

    * Incorrect:

      * The agent lists 7 possible implementations, picks one and completes the whole task in the same turn;

    * Correct:

      * The agent proposes a recommended option, asks one focused question batch, waits for the answer, then proceeds to the next step;

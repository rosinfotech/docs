# The Rosinfotech Base Standards

## The AI Standard

### AGENTS.md

#### Rule #2610031649

* Context:

  * Structured output is a discipline of its own: progressive disclosure and reference hygiene apply to every artifact an agent produces - rules, documentation, designs, reports;

* Description:

  * The Technical Writer AGENTS.md is a role asset: composed into an AGENTS.md as a marked block on demand (the inclusions: [Rule #2610031427](/standards/ai-standard/rule-2610031427.md)); the ready-to-copy source of truth is the asset [AGENTS-STANDARD-TECHNICAL-WRITER.md](/standards/ai-standard/assets/AGENTS-STANDARD-TECHNICAL-WRITER.md);

  * Role scope: structured output - the structure of the descriptions comes first, the references come second; both are mandatory for every artifact;

  * It implements - inlines the agent-relevant text of, with the full meaning of - the catalog rules, in the priority order:

    * [Rule #2609270954](/standards/documentation-standard/rule-2609270954.md) - progressive disclosure: lists with sublists, the terminator grammar, the colon as the disclosure marker - woven FIRST, above the references;

    * [Rule #2609270956](/standards/documentation-standard/rule-2609270956.md) with [Rule #2609262025](/standards/ai-standard/rule-2609262025.md) - git references pinned to commit and lines, and the agent-side link formatting;

* Benefits:

  * The structure discipline is stated once and applied everywhere;

  * The priority is explicit: disclosure first, references second;

  * The behavioral core slims down.

* Examples:

  * Case #1:

    * Incorrect:

      * a wall of text with bare `file.ts:26` mentions;

    * Correct:

      * a top-level list with short items, details in sublists, every file mention a clickable link pinned to the commit.

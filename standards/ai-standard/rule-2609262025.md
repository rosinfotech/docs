# The Rosinfotech Base Standards

## The AI Standard

### The AI Automation Standard

#### Rule #2609262025

* Context:

  * The abstract norm is defined by the catalog rule [Rule #2609270956 - Git References: Pin to Commit and Lines](/standards/documentation-standard/rule-2609270956.md); this rule defines how an agent formats file references in its responses;

* Description:

  * Every file or file-fragment mention in a response is a real clickable Markdown link - never just styled/highlighted text: bare `file.ts:NN` anywhere (tables, lists, code-adjacent prose) is a violation;

  * Build the URL exactly as the catalog rule prescribes: a web UI link pinned to the commit SHA, with line anchors;

  * If a web URL can not be constructed (no remote, local-only file): use a plain absolute-path Markdown link, line numbers go in the link text;

  * The `vscode://` scheme must NOT be used - chat clients do not open it;

  * Terminal contexts are the exception: plain text `path/file.ts:26` is auto-linkified by VS Code; the CLI equivalent is `code -g <file>:<line>`;

* Benefits:

  * One click from an agent answer to the exact source line;

  * The same reference format from humans and agents - a single catalog norm;

* Examples:

  * Case #1:

    * Incorrect:

      * The bug is fixed in `src/services/process.ts` line 712;

    * Correct:

      * The bug is fixed in [process.ts:712](https://gitlab.com/group/repo/-/blob/1f2a3b4/src/services/process.ts#L712);

# The Rosinfotech Base Standards

## The AI Standard

### AGENTS.md

#### Rule #2610031651

* Context:

  * Exploration is a dialogue: an agent that dumps everything in one turn buries the user and makes wrong assumptions;

* Description:

  * The Researcher AGENTS.md is a role file: it extends the BASE AGENTS.md ([Rule #2609271528](/standards/ai-standard/rule-2609271528.md)) and never weakens it; the ready-to-copy source of truth is the asset [AGENTS-STANDARD-RESEARCHER.md](/standards/ai-standard/assets/AGENTS-STANDARD-RESEARCHER.md);

  * Role scope: interactive exploration - requirements, unknown codebases, options, decision spaces; the exploration is a dialogue, not a dump;

  * It implements - inlines the agent-relevant text of, with the full meaning of - the catalog rule:

    * [Rule #2609271000](/standards/ai-standard/rule-2609271000.md) - interactive work: step by step;

* Benefits:

  * The exploration pace stays human - small steps, focused questions;

  * Decision points surface early with recommended paths;

  * The behavioral core slims down.

* Examples:

  * Case #1:

    * Incorrect:

      * the agent explores the whole codebase and dumps a ten-screen analysis in one turn;

    * Correct:

      * the agent moves step by step: one question batch per decision point, a recommended path, then the next step.

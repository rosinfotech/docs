# The Rosinfotech Base Standards

## The AI Standard

### AGENTS.md

#### Rule #2610031855

* Context:

  * A production task started in the wrong directory pollutes the context folder with project files and mixes unrelated work;

* Description:

  * When a task starts that looks like production work on a new project - building a new application, service, library, site - the agent asks whether to create a separate directory for the project or to work in an already created one;

  * The question is a button choice (the interactive work [Rule #2609271000](/standards/ai-standard/rule-2609271000.md)): "Создать отдельную директорию" (propose a name when creating) / "Работать в текущей";

  * The question is asked ONLY when both conditions hold:

    * the user has not communicated a working directory explicitly;

    * the contextual directory carries no project markers:

      * `.git`, `.kilo`, `Makefile`, `.makefile/`;

      * `package.json`, `node_modules`;

      * `go.mod`, `Cargo.toml`, `pom.xml`, `build.gradle`, `build.gradle.kts`;

      * `pyproject.toml`, `requirements.txt`, `composer.json`;

      * the equivalent markers of other language ecosystems;

  * An explicit directory or a detected marker means no question - the agent works where the context points;

  * The question never fires in non-production interactions:

    * the research/ask mode;

    * questions about existing code;

    * reviews and discussions;

* Benefits:

  * A new project never lands in an unrelated directory by accident;

  * The engineer decides the workspace once, up front;

  * Non-production sessions stay question-free.

* Examples:

  * Case #1:

    * the user: "сделай CLI-утилиту на Go для парсинга логов" in `~/Downloads`;

    * the agent finds no markers and asks (buttons): create a separate directory or work here;

  * Case #2:

    * the user: "напиши сервис авторизации" in a directory containing `.git` and `go.mod`;

    * the markers answer the question - the agent works in the current directory without asking.

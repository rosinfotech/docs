# The Rosinfotech Base Standards
## The JavaScript Code Style Standard

### Variables

#### Rule #2605280102

* Description:

  * In JavaScript and TypeScript unused variables, function arguments, and caught errors are forbidden unless their name starts with an underscore (`_`);

  * ESLint rules:

    * `no-unused-vars` (JavaScript, [eslint-config-javascript](https://github.com/rosinfotech/eslint-config-javascript));

    * `@typescript-eslint/no-unused-vars` (TypeScript, [eslint-config-typescript](https://github.com/rosinfotech/eslint-config-typescript));

    * the ignore patterns `argsIgnorePattern`, `caughtErrorsIgnorePattern` and `varsIgnorePattern` are set to `'^_'`;

* Benefits:

  * Code cleanliness — removes dead code;
  * Explicit intent — underscore prefix signals a deliberately unused binding;
  * Maintainability — easier to spot accidentally unused variables;

* Examples:

  * Case #1:

    * Incorrect:

      ```typescript
      const onClick = ( event, context ) => {
          doSomething( context );
      };
      ```

    * Correct:

      ```typescript
      const onClick = ( _event, context ) => {
          doSomething( context );
      };
      ```

  * Case #2:

    * Incorrect:

      ```typescript
      try {
          riskyOperation();
      } catch ( error ) {
          notifyAdmin();
      }
      ```

    * Correct:

      ```typescript
      try {
          riskyOperation();
      } catch ( _error ) {
          notifyAdmin();
      }
      ```

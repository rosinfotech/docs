# The Rosinfotech Base Standards

## The Documentation Standard

### Structure

#### Rule #2609270954

* Context:

  * A flat description overloads the reader with details; a wall of text hides the top-level picture;

* Description:

  * Structure the given descriptions by Progressive Disclosure: everything goes as a list, and the details of different list items are disclosed by sublists;

  * The top-level list gives the complete picture in short items; each next level discloses details of its parent item only;

  * Every list item ends with exactly one terminator:

    * ";" (semicolon) - the item is final: it has NO child items;

    * ":" (colon) - the item MUST be followed by child items disclosing its details;

  * An item ending with ":" without child items is a violation;

  * An item ending with ";" MUST NOT have child items;

  * The colon inside an item is the disclosure marker: when the text after a colon enumerates parallel items, they become child items - an inline enumeration after a colon is a violation; a single clarifying clause after a colon may stay in the item;

* Benefits:

  * Scannability - the top level reads as a complete summary;

  * Predictable grammar - the terminator tells the reader whether to expect details;

  * Depth control - details never bury the big picture;

* Examples:

  * Case #1:

    * Incorrect (":" without children; leaf item without ";"):

      ```text
      * Deploy the server:
      * Install dependencies
      ```

    * Correct:

      ```text
      * Deploy the server:
        * copy artifacts;
        * restart the service;
      * Install dependencies;
      ```

  * Case #2 - deeper disclosure:

    ```text
    * Deploy the server:
      * copy artifacts:
        * strip debug symbols;
        * preserve the executable bit;
      * restart the service;
    ```

  * Case #3 - an inline enumeration after a colon:

    * Incorrect:

      ```text
      * Toolchain: build `go build`, test `go test`;
      ```

    * Correct:

      ```text
      * Toolchain:
        * build: `go build`;
        * test: `go test`;
      ```

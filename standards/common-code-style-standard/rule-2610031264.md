# The Rosinfotech Base Standards

## The Common Code Style Standard

### Formatting

#### Rule #2610031264

* Context:

  * Overlong lines break review diffs and side-by-side view; mixed line endings and BOM break tooling;

* Description:

  * The line length is at most 100 characters (`printWidth: 100`);

  * Line endings are LF only (`endOfLine: "lf"`) - never CRLF, never CR;

  * No byte order mark at the file start (`unicode-bom: never`);

  * Enforcement - the rule is supported by the repository [prettier-config-standard](https://github.com/rosinfotech/prettier-config-standard);

* Benefits:

  * Two files fit side by side in review;

  * Platform-independent line endings;

  * Clean byte-exact diffs.

* Examples:

  * Case #1:

    * Incorrect (115 characters):

      ```javascript
      const validationResult = validateUserRegistrationFormDataBeforeSubmittingTheFormToTheServerEndpoint(userRegistrationFormDataObject);
      ```

    * Correct:

      ```javascript
      const validationResult = validateRegistrationFormData(
          userRegistrationFormDataObject,
      );
      ```

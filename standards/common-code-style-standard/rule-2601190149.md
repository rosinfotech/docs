# The Rosinfotech Base Standards

## The Common Code Style Standard
### The Name Convention

#### Files and directories

##### Rule #2601190149

* Context:

  * Directories;

  * All languages;

* Positions:

  * Kebab case;

  * Suffix name convention;

  * Abbreviations in lowercase;

* Examples:

  * Incorrect:

    * `./src/GPRCControllers/ControllerCommunicator.ts`;

  * Correct:

    * `./src/gprc-controllers/CommunicatorController.ts`;

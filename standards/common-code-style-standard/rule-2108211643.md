# The Rosinfotech Base Standards

## The Common Code Style Standard
### The Name Convention

#### Variables

##### Paths and files

##### Rule #2108211643

* Description:

  * Variables containing file name without extension use "FileNoExtension" suffix;

* Benefits:

  * Clarity;
  * Uniformity;

* Examples:

  * Case #1

    * Incorrect:

      ```typescript
      const myNotes = `my_notes`;
      ```

    * Correct:

      ```typescript
      const myNotesFileNoExtension = `my_notes`;
      ```

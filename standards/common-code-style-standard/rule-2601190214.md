# The Rosinfotech Base Standards

## The Common Code Style Standard
### The Name Convention

#### Files and directories

##### Rule #2601190214

* Context:

  * Files;

  * Languages:

    * Bash;

* Positions:

  * Snake case;

  * Suffix name convention;

  * Abbreviations in lowercase;

* Examples:

  * Incorrect:

    * `./src/.makefile/KillProcesses.sh`;

  * Correct:

    * `./src/.makefile/kill_processes.sh`;

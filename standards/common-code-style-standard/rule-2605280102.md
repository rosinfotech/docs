# The Rosinfotech Base Standards

## The Common Code Style Standard
### The Name Convention

#### Types

##### TypeScript

##### Rule #2605280102

* Description:

  * Unused variables, function arguments, and caught errors are forbidden unless their name starts with an underscore (`_`);

  * ESLint rule: `@typescript-eslint/no-unused-vars` with `argsIgnorePattern`, `caughtErrorsIgnorePattern`, and `varsIgnorePattern` set to `'^_'`;

* Benefits:

  * Code cleanliness — removes dead code;
  * Explicit intent — underscore prefix signals a deliberately unused binding;
  * Maintainability — easier to spot accidentally unused variables;

* Examples:

  * Case #1:

    * Incorrect:

      ```typescript
      const onClick = ( event, context ) => {
        doSomething( context );
      };
      ```

    * Correct:

      ```typescript
      const onClick = ( _event, context ) => {
        doSomething( context );
      };
      ```

  * Case #2:

    * Incorrect:

      ```typescript
      try {
        riskyOperation();
      } catch ( error ) {
        notifyAdmin();
      }
      ```

    * Correct:

      ```typescript
      try {
        riskyOperation();
      } catch ( _error ) {
        notifyAdmin();
      }
      ```

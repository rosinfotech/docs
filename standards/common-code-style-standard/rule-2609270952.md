# The Rosinfotech Base Standards

## The Common Code Style Standard

### Tabular data

#### Rule #2609270952

* Context:

  * CSV requires quoting and escaping: commas and quotes inside values force quoted fields, doubled quote characters and parser edge cases;

* Description:

  * When storing or exchanging tabular data (exports, dumps, fixtures, reports), ALWAYS prefer TSV over CSV;

  * TSV is the default choice for every new tabular data file in company repositories;

  * CSV is acceptable only when an external system requires it (an import/export interface with no TSV support);

* Benefits:

  * No quoting: commas, semicolons and quotes inside values need no escaping;

  * Simpler and faster parsing;

  * Column-aligned and readable in editors and terminals;

  * Diff-friendly;

* Examples:

  * Case #1:

    * Incorrect (CSV - the comma inside the value forces quoting):

      ```text
      name,description,price
      "Widget, large","5mm steel",42
      ```

    * Correct (TSV - fields separated by tab characters):

      ```text
      name	description	price
      Widget, large	5mm steel	42
      ```

# The Rosinfotech Base Standards

## The Common Code Style Standard

### Indentation

#### Rule #2610031272

* Context:

  * The source code indentation is 4 spaces ([Rule #2609270950](/standards/common-code-style-standard/rule-2609270950.md)); Markdown lists are prose structure, not source code - the ecosystem (markdownlint MD007, Prettier `tabWidth: 2`) and this catalog itself use a 2-space step;

* Description:

  * This rule is the Markdown exception of [Rule #2609270950](/standards/common-code-style-standard/rule-2609270950.md): in `*.md` files the nested lists use a 2-space step per nesting level;

  * Source code inside fenced code blocks keeps its own language rules (4 spaces and so on) - the exception covers only the list structure of the document;

  * The shared formatter enforces the step ([prettier-config-standard](https://github.com/rosinfotech/prettier-config-standard) overrides `tabWidth: 2` for `*.md`);

* Benefits:

  * Matches the ecosystem tooling defaults;

  * The catalog conforms without reformatting;

  * The source code rule stays intact.

* Examples:

  * Case #1:

    * Incorrect:

      ```markdown
      * Item:
          * Sub item;
      ```

    * Correct:

      ```markdown
      * Item:
        * Sub item;
      ```

# The Rosinfotech Base Standards

## The Common Code Style Standard

### Indentation

#### Rule #2609270950

* Context:

  * Mixed tabs and spaces break alignment across editors, terminals and diffs; the tab width is editor-dependent;

* Description:

  * The indentation unit is 4 space characters;

  * The tab character is not used for indentation anywhere in the source code;

  * Each nesting level adds exactly one indentation unit (4 spaces);

  * Alignment inside a line (continuations, table columns) may use any number of spaces - this rule covers only the leading indentation;

* Benefits:

  * Uniform rendering in any editor regardless of its tab-width setting;

  * Clean diffs - indentation changes never mix with content changes;

  * No per-editor configuration required;

* Examples:

  * Case #1:

    * Incorrect (the line starts with a tab character):

      ```typescript
      function format(value: string) {
      	return value.trim();
      }
      ```

    * Correct (the line starts with 4 spaces):

      ```typescript
      function format(value: string) {
          return value.trim();
      }
      ```

  * Case #2 - nesting levels:

    ```typescript
    if (value) {
        if (value.length > 3) {
            return true;
        }
    }
    ```

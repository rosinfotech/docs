# The Rosinfotech Base Standards

## The Common Code Style Standard
### The Name Convention

#### Base principles

##### Rule #2108211519

* Description:

  * Abbreviations is use in uppercase if the concrete naming concept include uppercase;

* Benefits:

  * Readability;
  * Uniformity;

* Examples:

  * Case #1:

    * Incorrect:

      ```typescript
      const licenseMitText = await fileRead(licenseMitPathFile);
      ```

    * Correct:

      ```typescript
      const licenseMITText = await fileRead(licenseMITPathFile);
      ```

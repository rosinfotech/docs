# The Rosinfotech Base Standards

## The Common Code Style Standard
### The Name Convention

#### Base principles

##### Rule #2103051010

* Description:

  * Unified Timestamp Label (UTLBL) - simple approach to unique identify anything;

* Types:

  * Short – YYMMDDHHMM;
  * Extended – YYMMDDHHMMSS;
  * User extended – YYMMDDHHMMSSUU;

* Benefits:

  * Sortable;
  * Structurity;
  * Uniformity;

* Examples:

  * Case #1:

    * Error label identify:

      ```typescript
      new ErrorLabeled("2103051010");
      ```

  * Case #2:

    * File name:

      * `2103051010-rule.md`

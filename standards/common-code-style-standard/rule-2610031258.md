# The Rosinfotech Base Standards

## The Common Code Style Standard

### Imports

#### Rule #2610031258

* Context:

  * Imports are the dependency surface of a module; undisciplined imports hide the structure and let cycles in;

* Description:

  * Imports go at the top of the file, before any other statement (`import-x/first`);

  * Group order (`import-x/order` groups):

    * type imports;

    * built-in;

    * external;

    * internal - the `@/**` paths count as internal (`import-x/order` pathGroups);

    * index;

    * parent;

    * sibling;

  * Inside a group the imports are alphabetized, case-insensitive, ascending (`import-x/order` alphabetize);

  * Hygiene (`eslint-plugin-import-x`):

    * no duplicate imports of the same module (`import-x/no-duplicates`);

    * no empty named import blocks (`import-x/no-empty-named-blocks`);

    * no useless path segments (`import-x/no-useless-path-segments`);

    * no unused exported modules (`import-x/no-unused-modules`);

  * Side-effect imports are allowed only for styles (`import-x/no-unassigned-import`):

    * `**/*.css`;

    * `**/*.scss`;

  * No import cycles: a module must not import itself transitively (`import-x/no-cycle`);

  * Two blank lines separate the import block from the code (`import-x/newline-after-import` count 2);

  * Enforcement - the rule is supported by the repository [eslint-config-import](https://github.com/rosinfotech/eslint-config-import);

* Benefits:

  * The dependency direction is visible at a glance;

  * Cycles surface early, at the lint step;

  * Deterministic file heads - no per-author import styles.

* Examples:

  * Case #1:

    * Incorrect:

      ```javascript
      import { Card } from "@/components/Card";
      import fs from "fs";
      import { Button } from "@/components/Button";
      ```

    * Correct:

      ```javascript
      import type { IOptions } from "./options";
      import fs from "fs";
      import { Button } from "@/components/Button";
      import { Card } from "@/components/Card";



      export function main() {
          // ...
      }
      ```

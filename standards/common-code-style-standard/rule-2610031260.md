# The Rosinfotech Base Standards

## The Common Code Style Standard

### Declarations

#### Rule #2610031260

* Context:

  * Usage before declaration forces the reader to scroll; implicit globals break tooling and modules;

* Description:

  * No undeclared variables (`no-undef`);

  * A name is declared before its usage point: variables, enums and type definitions (`no-use-before-define`); functions and classes are exempt - hoisting makes them safe;

  * One declaration per statement (`one-var: never`);

  * The immutable binding is preferred when the value is never reassigned (`prefer-const`);

  * Enforcement - the rule is supported by the repository [eslint-config-javascript](https://github.com/rosinfotech/eslint-config-javascript);

* Benefits:

  * Top-down readability - the declaration precedes the use;

  * No accidental globals;

  * Immutability is the default.

* Examples:

  * Case #1:

    * Incorrect:

      ```javascript
      console.log(total);

      let total = compute();

      let a = 1, let b = 2;
      ```

    * Correct:

      ```javascript
      const total = compute();

      console.log(total);

      const a = 1;
      const b = 2;
      ```

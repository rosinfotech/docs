# The Rosinfotech Base Standards

## The Common Code Style Standard
### The Name Convention

#### Files and directories

##### Rule #2601190331

* Context:

  * Files;

  * JavaScript/TypeScript;

  * Frontend;

* Positions:

  * Kebab case;

  * Suffix name convention;

  * Abbreviations in lowercase;

* Examples:

  * Case #1:

    * Incorrect:

      * `./src/utils/StringToHash.ts`;

    * Correct:

      * `./src/utils/string-to-hash.ts`;

  * Case #2:

    * Incorrect:

      * `./src/utils/RGBtoCMYK.ts`;

    * Correct:

      * `./src/utils/rgb-to-cmyk.ts`;
